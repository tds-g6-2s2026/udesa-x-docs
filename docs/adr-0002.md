# ADR-0002. Una base de datos por servicio, sin claves foráneas entre servicios

- Estado: Aceptada
- Fecha: 2026-08-19
- Alcance: auth, posts, social, media y admin

## Contexto

Compartir tablas acopla esquemas y despliegues.

## Decisión

Cada servicio su Postgres, UUID sin FK, lectura por API, migraciones propias (Alembic/goose).

## Alternativas

Base compartida. FK entre servicios.

## Consecuencias

Esquemas independientes. En contra: integridad referencial en código.
