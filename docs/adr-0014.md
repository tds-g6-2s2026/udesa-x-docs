# ADR-0014. App mobile con Expo, TanStack Query y Zustand

- **Estado:** Aceptada
- **Fecha:** 2026-08-25
- **Alcance:** mobile-app

## Contexto

La app principal tiene que ser mobile, y el equipo necesitaba probarla en dispositivos reales sin experiencia previa en desarrollo nativo para iOS y Android.

## Decisión

Usamos React Native 0.81 con Expo SDK 54 y TypeScript.

- **Estado del servidor** (feed, posts, perfil): TanStack Query, con claves de caché y actualizaciones optimistas que se corrigen con la respuesta del servidor.
- **Estado propio de la app:** Zustand. La sesión guarda el token cifrado en SecureStore; el tema se guarda en AsyncStorage.
- **Formularios, navegación e idiomas:** React Hook Form con Zod, React Navigation e i18next.

Cuando cambia el token, la caché se vacía entera para no mostrar datos de otra sesión.

## Alternativas

- Flutter.
- Redux para todo el estado.

## Consecuencias

A favor:

- Una sola base de código para iOS y Android, que se prueba con Expo Go.
- La interfaz responde al instante gracias a las actualizaciones optimistas.

En contra:

- Las notificaciones push con Firebase de la épica E.4 requieren un build propio: Expo Go no alcanza.
- La versión de Expo Go del teléfono tiene que coincidir con el SDK del proyecto.
